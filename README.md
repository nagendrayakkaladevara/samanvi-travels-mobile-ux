# Samanvi Travels mobile UX

An interactive design prototype for the Samanvi Travels driver announcement app. It presents 31 mobile screens and states covering sign-in, route selection, stop announcements, quick break announcements, Bluetooth speaker status, playback, settings, and the future records feature.

Open [the live prototype](https://nagendrayakkaladevara.github.io/samanvi-travels-mobile-ux/) after GitHub Pages is enabled, or open `index.html` locally in a browser.

The prototype uses sample data. MP3 playback, Bluetooth connections, and authentication are simulated; this repository is a UX deliverable, not the finished mobile application.

## Navigation

- **Overview** shows the main flows at a glance.
- **Prototype** lets you explore the screens and states interactively.
- **All 31 states** displays the complete screen set.

Home greets the driver and contains the quick lunch, dinner, and toilet announcements. Announcements focuses on the selected route's stops. Records has a coming-soon state.

The SVG source screens are in `Samanvi-Premium-UX/` for design review and import into Figma.
